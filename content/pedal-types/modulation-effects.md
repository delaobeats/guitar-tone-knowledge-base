# Modulation Effects

Modulation pedals change some aspect of the guitar signal over time. Unlike a drive pedal, which mainly changes saturation, modulation can create motion, width, or a pulsing rhythm. Chorus, phaser, flanger, and tremolo are four useful starting points. They can be subtle enough to add character or dramatic enough to become the main sound of a song.

## Four Sounds to Recognize

| Effect | What to listen for |
| --- | --- |
| **Chorus** | A wider, layered sound, as though similar guitar parts are playing together |
| **Phaser** | A smooth, sweeping movement through the frequencies |
| **Flanger** | A pronounced whooshing or jet-like sweep |
| **Tremolo** | The volume rising and falling in a repeating pattern |

Modulation pedals often include **rate** and **depth** controls. Rate changes the speed of the movement, while depth changes how strongly the effect is heard. The labels vary by pedal, so the best way to learn is to adjust one knob at a time.

### Build an Atmospheric Guitar Layer

1. Choose a clean chord progression.
2. Start with a slow chorus or phaser at a low depth setting.
3. Add [[pedal-types/delay-and-reverb|delay or reverb]] and listen for the motion in the tail of each chord.
4. Record a dry version and an effected version so you can compare how each sits in a mix.

This approach is useful for ambient introductions, quiet transitions, and the contrast between clean and heavy sections. It also shows why an effect that sounds impressive alone is not always the best one for an entire band arrangement.

## Pedal Order and Tone

Placing modulation after [[pedal-types/overdrive-and-distortion|distortion]] usually makes the sweep more distinct, while moving it earlier can make the drive change the modulation's character. The results depend on the exact pedals. If the sound becomes too bright or crowded, revisit [[pedal-types/compression-and-eq|EQ and dynamics]] before assuming the modulation is the problem.
